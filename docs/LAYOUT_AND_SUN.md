# 草坪裁切、卡槽留边与阳光循环

2026-10-06，分别用于还原版 v1.1.0 和 Mod v0.5.0。本轮经用户授权同步两个 GitHub 仓库；之后 Mod 仍按约定，用户要求时再上传。

## 从实际画面定位裁切问题

检查了用户指定的 PID 19340 对应原版窗口及本地解包背景。右侧人行道与道路已经在同一张 1400×600 的 `background1.jpg` 里，并非漏导入的另一张地图。

旧版从 x=160 起裁切 800 像素，背景可见范围为原图 [160,960)，九列格子也从 x=80 一直铺到视口 x=800。因此最后一列贴着屏幕右边，道路几乎全部被裁掉，草坪显得拥挤。

本版背景偏移改为 -220，格子从 x=40 起，保持每格 80×100、九列五行，横向范围为 [40,760)。可见宽度扩为 900，显示原图 [220,1120)，保留草坪右边缘、人行道和一段真正的道路。地图没有多加一列，也没有横向拉伸植物或背景。道路是装饰，不能种植物。

左侧推车停车位置随草坪对齐为 x=-20，参考原版接近 -21 的停车位置；推车移动速度和伤害规则保留。首个接触检查应允许推车从停车处实际移动到僵尸，不能依赖旧位置的即时碰撞。

## 卡槽不再贴住角落

卡槽、种子按钮、阳光计数与铲子挂在同一 `SeedBar` 节点下，整体移动到 (10,6)。移动可见贴图的同时，点击区域与阳光回收目标一起移动。菜单完整落在右上角，底部进度条靠右，暂停和结算面板按新宽度居中。

还原版使用 900×600。Mod 使用 900×640，顶部额外空间从上版 90 像素缩为 40 像素，卡槽重新覆盖一部分上方围栏区域，避免过厚的工具区让草坪显得隔得太远。第一排三档向日葵帽子在充能放大时的最小边界 y=107.99，卡槽下边缘约 y=94；充能条、军帽及脚边生产条仍同时可见。

Mod 沿用世界根节点偏移与 HUD 分离。局部物理坐标、屏幕鼠标坐标、动画枪口/断肢世界坐标、阳光跨 HUD 的坐标转换仍必须分别处理。上版复用文档继续保留历史方案。

## 阳光为什么转一下就变静态

Sun 原动画有 Sun1、Sun2、Sun3 三层：亮心、两层旋转/缩放/透明度变化的光芒。转换器对无标签动画通过首尾数值是否接近判断循环。阳光转了一段角度，旋转与位置首尾数值不同，虽然视觉形状能周期重复，却被识别成一次性片段；原片段长度约 1.083 秒，播放完就停止。

社区 [Coin.cpp](https://github.com/ruslan831/PlantsVsZombies-decompilation/blob/master/Lawn/Coin.cpp) 在初始化阳光时明确设置 `REANIM_LOOP` 和 `mAnimRate=6`。因此不能把“数值不闭合”直接当成“原游戏只播放一次”的证据。

修复在 `ActorView` 的阳光类型中完成：

- 复制当前阳光的动画资源，再设置循环，避免修改所有实例共享的导入资源。
- 原转换帧率为 12，以 0.5 倍播放速度还原 6 fps，单循环约 2.167 秒。
- 保留原三层位置、旋转、缩放、透明度；没有旋转整颗静态图标，亮心仍保持稳定。
- 使用现有手动动画时钟，暂停会停转；换到 HUD 后收集飞行期间继续播放。

不改社区转换器的通用规则，以免将水花、耙子等真实一次性动画强行循环。即使重新导入素材，运行时也会恢复阳光的正确循环策略。

## 可复用验证方式

布局先确认原贴图完整尺寸及裁切范围，再检查草坪边缘、所有格子、道路、工具区、推车、弹窗与鼠标命中。不要只移动背景而保留旧网格，也不要只移动卡片贴图而漏掉计数、铲子或阳光回收目标。

动画必须观察超过一次片段长度、至少一个完整循环，以及收集和暂停状态。短于一秒的预览无法发现此次“播完停住”。循环设置应同时核对资源属性和实际 `get_playing_speed()`，后者包含 `play()` 的自定义速度。

- `tests/layout_sun_test.gd`：14 项边界、卡槽、回收目标、原版速度、独立资源、连续循环、暂停与飞行检查。
- `tests/layout_sun_render_test.gd`：7 项实际鼠标与 GPU 检查，确认道路可见、最后一格可种、阳光早期与多个循环之后仍变化。
- 还原版：150 项既有回归加 21 项新增，共 171 项；正常经济三波胜利，188.3 秒、15/15。
- Mod：330 项既有回归加 21 项新增，共 351 项；正常经济一次操控一株的通关程序胜利，226.6 秒、152 次完整长按、15/15。费用、冷却、敌人参数与向日葵 24/40/60 秒窗口保留。

两个 8 秒实际 GPU 预览由 `tests/capture_layout_sun.gd` 和 Godot Movie Maker 生成，分别保存为 `build/v1.1-layout-sun.mp4`、`build/mod-v0.5.mp4`。预览的高起始阳光只用于展示，不进入正常游戏。

本地完整阶段包保留所选素材、预览、测试日志及逐文件 SHA-256。GitHub 同步代码、工具、文档，素材来源仍明确为 **PVZ 汉化2版（1.0.0.1051 CN V2）**；原版资源、军帽、完整本地归档与预览不加入公开源码树。
