# 阶段约定

后续改动先归入明确阶段，再实施。v1 验收前不增加植物、地图或新机制。

## v0：最小玩法基线（已保留）

白天 5×9 草坪、三种植物、普通/路障僵尸、阳光、飞行豌豆、啃食、铲子、小推车、暂停、重开、三波胜负。

v0 快照：`versions/v0.zip`。
包含当时源码和已选资源，不含导入缓存、完整原版解包缓存或构建预览。

## v1：现有内容的 UI 和动画还原

- 原版 50×70 种子卡：点击区、费用、静态缩略图和冷却遮罩对齐。
- 草坪行原点恢复为 y=80；第五行完整可种植。植物、僵尸、推车使用各自落点，加入原版阴影。
- 推车待机冻结，启动后轮子/引擎动画运行；使用 0.85 缩放和启动音效。
- 豌豆身体和头部独立播放，射击动画以 35 fps 播放，0.35 秒前摇后在嘴部生成子弹，接发射音、命中闪白和原版碎屑。
- 植物受击闪白；坚果低于 2/3、1/3 血量时使用两档原版破损图。植物独立眨眼。
- 僵尸低于 2/3 血量断臂、低于 1/3 掉头；残臂换图、部件掉落、路障三档破损。无头僵尸停止啃食并衰减血量，最后倒地淡出。
- 原版风格菜单、按钮、进度条。角色、尸体、粒子和音效一起暂停；结算后尸体可以完成淡出。
- 多声道音效池，避免同帧发射、啃食和命中声音直接相互打断。

2. [PlantsVsZombies-decompilation](https://github.com/ruslan831/PlantsVsZombies-decompilation)，检查 `Lawn/Plant.cpp`、`Zombie.cpp`、`LawnMower.cpp`、`SeedPacket.cpp`、`Board.cpp`。核对尺寸、坐标、前摇、闪白、阈值和推车状态；未并入其 C++ 代码。
3. [pvz2godot](https://github.com/ec50n9/pvz2godot)，继续使用 v0 固定提交的转换器，新增其 `particles2godot.py` 解码本地 `ZombieHead`、`ZombieArm`、`PeaSplat` 定义，保留 GPL-3.0 许可证。无损解码结果记录于 `original-particle-reference.json`。

### 验证

Godot 4.7.2 当前验证：22 项玩法检查、24 项表现检查、18 项联动与移动细节检查、36 项离散状态检查、33 项眨眼绑定检查、5 项实际 GPU 颜色检查，共 138 项通过；三波自动通关成功，击败 15/15 僵尸，约 188.2 秒。

`tests/capture_v1.gd` 生成实际 GPU 连续画面、破损场景与暂停菜单。预览是布置的验证场景，正常游戏主场景没有测试注入。

### 第二轮细节修正

修复着色器重复乘贴图造成的暗色、豌豆头部缺少茎部绑定、僵尸下巴误隐藏、匀速平移与行走动作不匹配。恢复 `_ground` 步态位移，平滑切换行走/啃食，避免接触穿入并正确计算接触时间。平均移动速度继续为 12 px/s。

处理方法与来源记录在 [ANIMATION_RENDERING.md](ANIMATION_RENDERING.md)，供后续同类问题复用。修改前快照位于 `versions/v1-initial.zip`，本轮全彩预览位于 `build/v1-detail.mp4`。

### 手部贴图切换修正（仍属 v1）

修复啃咬后恢复行走时残留张开手型的问题。保留 0.18 秒连续姿势混合，由 `reanim_discrete_state.gd` 在播放/推进后采样目标动作的贴图与显隐状态，再应用损伤覆盖。新增 36 项离散状态回归，覆盖反复切换、混合期间覆盖、完整循环、真实接触/恢复、断肢和段内换图；已更新 8 秒全彩预览。

从 v0 到当前 v1 的实际问题、原因、解决方式、失败尝试与可复用验证步骤统一收录于 [ANIMATION_RENDERING.md](ANIMATION_RENDERING.md)。
